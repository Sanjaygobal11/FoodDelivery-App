# Food Delivery Web Application 🍕🍔

A full-featured Food Delivery web application built with **Django** and **Python**. This project allows users to browse food categories, select items, manage their cart, and place orders.

---

## 🚀 Features

* **User Authentication:** Sign up, Login, and Session management.
* **Food Menu & Categories:** Browse items by categories (Fast Food, South Indian, Veg, Non-Veg, Desserts, etc.).
* **Cart System:** Add food items to the cart and manage order quantities.
* **Order Placement:** Checkout process with customer details and payment options.
* **Admin Panel:** Manage food items, categories, and customer orders via Django Admin.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript / Bootstrap
* **Database:** SQLite3
